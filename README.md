# odak-server

The central server of ODAK (Observe, Detect, Analyze, Know). It receives the aggregated numbers that the edge modules in the stores send, and it manages accounts and store links. It never receives video.

This repository currently contains the base files only. The project structure is created with the framework's own generator once the framework is chosen.
